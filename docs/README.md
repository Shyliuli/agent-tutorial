# Agent 入门与实战：从原理到日常工作

> **面向零基础、非计算机专业同学的智能体（Agent）教学教程。**  
> 核心原则：不讲玄学、不堆无用协议；用最通俗直白的语言讲清底层机制，用真实的上下文与工具武装日常工作。

## 本地阅读网页版

在仓库根目录执行以下两条命令，即可在浏览器中打开教程站点：

```bash
pip install mkdocs-material
mkdocs serve
```

如果只想生成静态文件，执行 `mkdocs build`，产物会出现在 `site/` 目录中，可以直接交给任意静态托管平台。
